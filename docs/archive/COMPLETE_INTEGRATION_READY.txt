📊 USER EXPERIENCE FLOW

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User opens app
   └─ Dashboard shows new "History" tab

2. User clicks "History"
   └─ SyncHistoryAndBackupView opens with 3 tabs

3. User selects "Timeline" tab
   ├─ Sees all sync operations with timestamps
   └─ Can filter by type, source, or date

4. User selects "Backups" tab
   ├─ Lists all backup sessions newest first
   ├─ Each can be expanded to see:
   │  ├─ Number of contacts
   │  ├─ Created timestamp
   │  ├─ Type (pre-sync, post-sync, manual)
   │  └─ Any notes/metadata
   ├─ Can Export backup as JSON
   └─ Can Restore from this backup

5. User clicks "Restore"
   ├─ RestoreBackupConfirmationView opens
   ├─ Shows:
   │  ├─ WARNING about replacing current contacts
   │  ├─ Backup details (timestamp, size, contents)
   │  ├─ What will happen (4 step process)
   │  └─ Confirm/Cancel buttons
   └─ Clicking Restore:
      ├─ Creates backup of current state
      ├─ Restores contacts to backup state
      ├─ Creates new post-restore backup
      └─ Updates sync history
      └─ Returns to Dashboard

6. User can also view "Statistics" tab
   ├─ Total backups count
   ├─ Total contact versions
   ├─ Storage space used
   ├─ Backup date range
   └─ Recommendations (clean up if >50 backups, etc.)
