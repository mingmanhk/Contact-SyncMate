THREE-LAYER BACKUP STRATEGY:

  LAYER 1: PRE-SYNC SNAPSHOTS
  ├─ Auto-created immediately after fetch
  ├─ Captures complete contact state BEFORE changes
  └─ Enables rollback if sync fails

  LAYER 2: POST-SYNC SNAPSHOTS  
  ├─ Auto-created after changes applied successfully
  ├─ Shows actual result + success/failure summary
  └─ For verification and comparison

  LAYER 3: VERSIONED HISTORY
  ├─ All versions per contact with version numbers
  ├─ Linked to sync sessions for full traceability
  ├─ Allows granular restore (single contact)
  └─ Complete audit trail maintained

DATA FLOW:
  [OLD] Fetch → Diff → Apply → Log
  [NEW] Fetch → [PRE-BACKUP] → Diff → Apply → [POST-BACKUP] → Log
               ↑                                  ↑
            Automatic                        Automatic
